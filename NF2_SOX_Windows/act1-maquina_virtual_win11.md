# Enunciat

L’empresa vol fer proves per les pròximes màquines del departament de desenvolupament. Per aquest motiu, us demana crear una màquina virtual (VirtualBox) i instal·lar un sistema operatiu **Windows 11 Enterprise**, considerant els requisits del sistema.

Aquesta màquina serà la base per crear un model d’equip.

# Accions a realitzar

1. Cerqueu els requisits que Microsoft indica per a la instal·lació de **Windows 11**. Feu un resum dels aspectes més destacats que haureu de tenir en consideració:
   - CPU
   - RAM
   - Espai de disc
   - Gràfics
   - Pantalla

   Deixeu aquests requisits en un document per mostrar durant la correcció.

2. Configureu la màquina virtual de manera que s’ajusti als requisits que heu trobat en el primer punt de l’activitat.

   Pel que respecta a la configuració de xarxa, la deixarem en el mode per defecte (**NAT**).

3. Instal·leu el sistema operatiu a la màquina virtual:
   1. Documenteu la pantalla de selecció d’idioma i teclat (**espanyol** i **teclat en espanyol**).
   2. Documenteu la pantalla on s’especifica la zona horària (**Europa/Madrid**).
   3. Creeu un usuari local que anomenareu **smx1A-NN**, on **NN** és el vostre **número de llista** si sou de 1r A, o **smx1B-NN** si sou de 1r B.
